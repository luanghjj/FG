# BỘ TỪ VỰNG TIẾNG ĐỨC CHUYÊN NGÀNH NHÀ HÀNG & KHÁCH SẠN (AZUBI.VN)

Trích xuất từ các chuyên đề đào tạo nghề nhà hàng khách sạn của Azubi.vn.

---

## 1. Từ Vựng Chuyên Ngành Nhà Hàng (Gastronomie & Restaurant)

| Thuật ngữ tiếng Đức | Nghĩa tiếng Việt | Ngữ cảnh ứng dụng |
| :--- | :--- | :--- |
| **die Speisekarte** | Thực đơn món ăn | Phục vụ bàn / Giới thiệu món |
| **die Getränkekarte** | Thực đơn đồ uống | Phục vụ quầy bar / bàn |
| **die Vorspeise** | Món khai vị | Thực đơn 3 món |
| **das Hauptgericht** | Món chính | Thực đơn chính |
| **die Nachspeise / das Dessert** | Món tráng miệng | Món ngọt sau bữa |
| **die Tagesempfehlung** | Món gợi ý trong ngày | Tư vấn khách hàng |
| **der Gast / die Gäste** | Thực khách | Chăm sóc khách |
| **der Kellner / die Kellnerin** | Nhân viên phục vụ bàn | Vị trí công việc |
| **die Rechnung** | Hóa đơn thanh toán | Thanh toán cho khách |
| **das Trinkgeld** | Tiền boa / Tip | Dịch vụ khách |
| **der Bewirtungsvertrag** | Hợp đồng dịch vụ ăn uống | Pháp lý & Nghiệp vụ |
| **die Besteckanordnung** | Cách sắp xếp dao thìa dĩa | Set up bàn ăn |
| **das Tischtuch** | Khăn trải bàn | Chuẩn bị bàn tiệc |
| **die Serviette** | Khăn ăn | Gấp khăn ăn |
| **die Reklamation** | Sự phàn nàn / khiếu nại của khách | Xử lý tình huống |
| **die Allergenkennzeichnung** | Ghi nhãn chất gây dị ứng | An toàn vệ sinh thực phẩm |
| **die Mehrwertsteuer (MwSt)** | Thuế giá trị gia tăng (7% / 19%) | Tính hóa đơn |

## 2. Từ Vựng Chuyên Ngành Khách Sạn (Hotellerie)

| Thuật ngữ tiếng Đức | Nghĩa tiếng Việt | Ngữ cảnh ứng dụng |
| :--- | :--- | :--- |
| **der Empfang / die Rezeption** | Quầy lễ tân | Tiếp đón khách |
| **der Check-in / der Check-out** | Thủ tục nhận / trả phòng | Lễ tân khách sạn |
| **die Zimmerreservierung** | Đặt phòng trước | Quản lý phòng |
| **die Buchungsbestätigung** | Xác nhận đặt phòng | Email / Văn bản |
| **das Einzelzimmer (EZ)** | Phòng đơn | Loại phòng |
| **das Doppelzimmer (DZ)** | Phòng đôi | Loại phòng |
| **die Suite** | Phòng cao cấp / Suite | Loại phòng |
| **das Housekeeping / die Zimmerreinigung** | Dọn dẹp buồng phòng | Vệ sinh & buồng phòng |
| **die Minibar** | Tủ lạnh nhỏ trong phòng | Kiểm tra tiêu dùng |
| **der Zimmerservice** | Dịch vụ phục vụ tại phòng | Room service |
| **die Kurtaxe** | Thuế du lịch địa phương | Thu phụ phí |
| **der Gepäckservice** | Dịch vụ vận chuyển hành lý | Bellboy |
| **die Stornierung** | Việc hủy phòng | Xử lý đặt phòng |
| **die Kaution** | Tiền đặt cọc phòng | Thanh toán |
| **das Fundsachenbüro** | Nơi lưu giữ đồ thất lạc (*Lost & Found*) | Chăm sóc khách hàng |
